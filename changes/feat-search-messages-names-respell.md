### Added

- **`search messages` helps a query of plain words the way `search conversations` does.** A word no message holds is
  searched beside its Latin spelling or nearest known spellings (`meta.respelled`, and a note). Without `chat:`, a word
  the messages show is a name in one private chat has that chat's hits first, searched without the name
  (`meta.named_chat`, and a note). A query with fields, quotes, groups or operators is searched exactly as written.
